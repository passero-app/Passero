# Passero iOS — Milestone 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove, for $0 on a real iPhone, that the existing Passero Svelte UI runs well on iOS and that a FaceID-gated software key can decrypt a `pass` entry and sync via git — the pre-spend gate for the whole iOS effort.

**Architecture:** Add an iOS target to the existing Tauri 2 project. Build a new pure-Rust `passero-core` crate (Sequoia `crypto-rust` backend for PGP, `git2` for sync) that reimplements the `pass` read/write path with no subprocess calls. On iOS only (`#[cfg(target_os = "ios")]`), route the existing Tauri command names to `passero-core`; desktop keeps its current subprocess backend untouched. Store the generated key in the iOS Keychain behind biometric access control via `tauri-plugin-keystore`.

**Tech Stack:** Tauri 2, Svelte 5 (existing UI, unchanged), Rust, `sequoia-openpgp` 2.3.x (`crypto-rust`, experimental), `git2`/libgit2, `tauri-plugin-keystore`, `tauri-plugin-biometric`.

**Spec:** `.docs/specs/2026-06-13-passero-ios-phase1-design.md` (§7 M0a/M0b, §11 Distribution).

**Scope note:** This plan is M0 only. M1–M4 (full read path, write path, UI integration polish, family onboarding) get their own plan after M0's exit gate is met and the $99 Apple Developer Program decision is made. TOTP, recipient-management UI, and the full GPG key-management surface are intentionally **out of M0 scope** (YAGNI for the gate).

**Pre-flight assumptions (verify before Task 1):**
- macOS with the full **Xcode** app installed (not just Command Line Tools), opened once to accept the license.
- An iPhone you can connect via USB, with a free Apple ID added in Xcode (Settings → Accounts).
- The desktop Passero app currently builds (`npm install && npm run tauri build` succeeds on this machine).
- Work happens on branch `spec-passero-ios-phase1`'s sibling implementation branch — create `ios-m0` off `origin/main` in a worktree before starting (see executing-plans / using-git-worktrees).

- [ ] **Step 3: Implement crypto.rs by adapting the canonical Sequoia example**

Implement these four functions in `passero-core/src/crypto.rs`, adapting the **verbatim upstream example** at
`https://gitlab.com/sequoia-pgp/sequoia/-/blob/main/openpgp/examples/generate-encrypt-decrypt.rs`
(check out the tag matching the resolved `sequoia-openpgp` 2.3.x in `Cargo.lock`). Required public API the tests above depend on:

```rust
use sequoia_openpgp as openpgp;
use openpgp::cert::Cert;

/// Generate an ed25519 OpenPGP cert. Returns the cert and its
/// armored secret-key bytes (for Keychain storage).
pub fn generate_key(user_id: &str) -> crate::Result<(Cert, Vec<u8>)>;

/// Parse a cert (with secret key material) from the bytes produced by generate_key.
pub fn cert_from_bytes(bytes: &[u8]) -> crate::Result<Cert>;

/// Encrypt plaintext to all given recipient certs. Returns OpenPGP message bytes.
pub fn encrypt(plaintext: &[u8], recipients: &[Cert]) -> crate::Result<Vec<u8>>;

/// Decrypt an OpenPGP message using the secret key in `key_cert`.
pub fn decrypt(ciphertext: &[u8], key_cert: &Cert) -> crate::Result<Vec<u8>>;
```

Implementation notes (from the example's shape):
- `generate_key`: `CertBuilder::general_purpose(Some(user_id))` then `.set_cipher_suite(CipherSuite::Cv25519)` → `.generate()` returns `(Cert, RevocationCert)`. Serialize secret bytes with `cert.as_tsk().armored().to_vec()`.
- `cert_from_bytes`: `Cert::from_bytes(bytes)`.
- `encrypt`: build `recipients` via `cert.keys().with_policy(p, None).supported().alive().revoked(false).for_transport_encryption()`; stream `Message::new(&mut sink)` → `Encryptor::for_recipients(...).build()` → `LiteralWriter::new(...).build()` → write plaintext → finalize each writer.
- `decrypt`: implement a `Helper` struct with `VerificationHelper` (return empty certs / accept) and `DecryptionHelper` (`decrypt` callback: take `pkesks`, find the secret key via `key_cert`, `into_keypair()`, call `pkesk.decrypt(&mut keypair, sym_algo)`, return the fingerprint). Drive with `DecryptorBuilder::from_bytes(ciphertext)?.with_policy(p, None, helper)?` and `io::copy` to a sink.
- Use `&StandardPolicy::new()` for the policy. Map all `anyhow`/sequoia errors into `CoreError::Crypto(e.to_string())`.

- [ ] **Step 3: Implement store.rs**

`passero-core/src/store.rs` — `pass` is just files; implement:
```rust
use std::path::{Path, PathBuf};
use crate::{crypto, Result, CoreError};
use sequoia_openpgp::cert::Cert;

/// Write the top-level `.gpg-id` recipient list.
pub fn init(store: &Path, gpg_ids: &[String]) -> Result<()> {
    std::fs::create_dir_all(store)?;
    std::fs::write(store.join(".gpg-id"), gpg_ids.join("\n") + "\n")?;
    Ok(())
}

/// Recursively list entry paths (relative, without the .gpg suffix), sorted.
pub fn list(store: &Path) -> Result<Vec<String>> {
    let mut out = Vec::new();
    walk(store, store, &mut out)?;
    out.sort();
    Ok(out)
}

fn walk(root: &Path, dir: &Path, out: &mut Vec<String>) -> Result<()> {
    for entry in std::fs::read_dir(dir)? {
        let path = entry?.path();
        let name = path.file_name().and_then(|s| s.to_str()).unwrap_or("");
        if name.starts_with('.') { continue; }            // skip .git, .gpg-id
        if path.is_dir() { walk(root, &path, out)?; }
        else if path.extension().and_then(|s| s.to_str()) == Some("gpg") {
            let rel = path.strip_prefix(root).unwrap().with_extension("");
            out.push(rel.to_string_lossy().replace('\\', "/"));
        }
    }
    Ok(())
}

/// Decrypt one entry to plaintext bytes.
pub fn show(store: &Path, entry: &str, key: &Cert) -> Result<Vec<u8>> {
    let file = store.join(entry).with_extension("gpg");
    let ciphertext = std::fs::read(file)?;
    crypto::decrypt(&ciphertext, key)
}

/// Encrypt plaintext to `recipients` and write `<entry>.gpg`, creating dirs.
pub fn insert(store: &Path, entry: &str, plaintext: &[u8], recipients: &[Cert]) -> Result<()> {
    let file = store.join(entry).with_extension("gpg");
    if let Some(parent) = file.parent() { std::fs::create_dir_all(parent)?; }
    let ciphertext = crypto::encrypt(plaintext, recipients)?;
    std::fs::write(file, ciphertext)?;
    Ok(())
}

/// Read the recipient fingerprints governing a subtree (nearest `.gpg-id`).
pub fn recipients_for(store: &Path, _entry: &str) -> Result<Vec<String>> {
    let gpg_id = store.join(".gpg-id");
    let text = std::fs::read_to_string(gpg_id)
        .map_err(|e| CoreError::Store(format!("no .gpg-id: {e}")))?;
    Ok(text.lines().map(|l| l.trim().to_string()).filter(|l| !l.is_empty()).collect())
}

#[allow(dead_code)]
fn _path_marker(_p: PathBuf) {}
```

- [ ] **Step 4: Implement sync.rs**

`passero-core/src/sync.rs` — git2 over HTTPS with a token credential callback:
```rust
use git2::{Repository, RemoteCallbacks, FetchOptions, PushOptions, Cred, Signature};
use std::path::Path;
use crate::Result;

/// Optional GitHub token used for HTTPS auth (set before sync on iOS from Keychain).
pub fn set_token(token: Option<String>) { TOKEN.with(|t| *t.borrow_mut() = token); }
thread_local! { static TOKEN: std::cell::RefCell<Option<String>> = const { std::cell::RefCell::new(None) }; }

fn callbacks<'a>() -> RemoteCallbacks<'a> {
    let mut cb = RemoteCallbacks::new();
    cb.credentials(|_url, username, _allowed| {
        TOKEN.with(|t| match &*t.borrow() {
            Some(tok) => Cred::userpass_plaintext("x-access-token", tok),
            None => Cred::username(username.unwrap_or("git")),
        })
    });
    cb
}

pub fn clone(url: &str, into: &Path) -> Result<Repository> {
    let mut fo = FetchOptions::new();
    fo.remote_callbacks(callbacks());
    let mut builder = git2::build::RepoBuilder::new();
    builder.fetch_options(fo);
    Ok(builder.clone(url, into)?)
}

pub fn pull(repo: &Repository) -> Result<()> {
    let mut fo = FetchOptions::new();
    fo.remote_callbacks(callbacks());
    repo.find_remote("origin")?.fetch(&["main"], Some(&mut fo), None)?;
    let fetch_head = repo.refname_to_id("FETCH_HEAD")?;
    let commit = repo.find_annotated_commit(fetch_head)?;
    let (analysis, _) = repo.merge_analysis(&[&commit])?;
    if analysis.is_fast_forward() {
        let mut r = repo.find_reference("refs/heads/main")?;
        r.set_target(fetch_head, "ff")?;
        repo.set_head("refs/heads/main")?;
        repo.checkout_head(Some(git2::build::CheckoutBuilder::new().force()))?;
    }
    Ok(())
}

pub fn commit_all(repo: &Repository, msg: &str) -> Result<()> {
    let mut index = repo.index()?;
    index.add_all(["*"].iter(), git2::IndexAddOption::DEFAULT, None)?;
    index.write()?;
    let tree = repo.find_tree(index.write_tree()?)?;
    let sig = Signature::now("Passero iOS", "passero@local")?;
    let parents = match repo.head().ok().and_then(|h| h.target()) {
        Some(oid) => vec![repo.find_commit(oid)?],
        None => vec![],
    };
    let parent_refs: Vec<&git2::Commit> = parents.iter().collect();
    repo.commit(Some("HEAD"), &sig, &sig, msg, &tree, &parent_refs)?;
    Ok(())
}

pub fn push(repo: &Repository) -> Result<()> {
    let mut po = PushOptions::new();
    po.remote_callbacks(callbacks());
    repo.find_remote("origin")?
        .push(&["refs/heads/main:refs/heads/main"], Some(&mut po))?;
    Ok(())
}
```

```rust
#![cfg(target_os = "ios")]
use passero_core::{store, sync, crypto};
use std::path::PathBuf;
use std::sync::Mutex;
use tauri::State;

pub struct IosState {
    pub store_dir: Mutex<PathBuf>,
    pub key_armored: Mutex<Option<Vec<u8>>>, // loaded from Keychain at unlock
}

fn key(state: &State<IosState>) -> Result<crypto::Cert, String> {
    let guard = state.key_armored.lock().unwrap();
    let bytes = guard.as_ref().ok_or("locked: no key loaded")?;
    crypto::cert_from_bytes(bytes).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn list_passwords(state: State<IosState>) -> Result<Vec<String>, String> {
    let dir = state.store_dir.lock().unwrap().clone();
    store::list(&dir).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn show_password(path: String, state: State<IosState>) -> Result<String, String> {
    let dir = state.store_dir.lock().unwrap().clone();
    let cert = key(&state)?;
    let bytes = store::show(&dir, &path, &cert).map_err(|e| e.to_string())?;
    String::from_utf8(bytes).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn git_pull(state: State<IosState>) -> Result<(), String> {
    let dir = state.store_dir.lock().unwrap().clone();
    let repo = git2::Repository::open(&dir).map_err(|e| e.to_string())?;
    sync::pull(&repo).map_err(|e| e.to_string())
}
```

- [ ] **Step 3: Add generate/unlock commands (iOS)**

Append to `src-tauri/src/ios/mod.rs`:
```rust
#[tauri::command]
pub fn generate_in_app_key(user_id: String, state: State<IosState>) -> Result<String, String> {
    let (cert, secret) = crypto::generate_key(&user_id).map_err(|e| e.to_string())?;
    *state.key_armored.lock().unwrap() = Some(secret);          // held in memory this session
    Ok(cert.fingerprint().to_string())                          // caller stores `secret` via keystore JS API
}

#[tauri::command]
pub fn load_key(armored: Vec<u8>, state: State<IosState>) -> Result<String, String> {
    let cert = crypto::cert_from_bytes(&armored).map_err(|e| e.to_string())?;
    *state.key_armored.lock().unwrap() = Some(armored);
    Ok(cert.fingerprint().to_string())
}

#[tauri::command]
pub fn clone_store(url: String, token: String, state: State<IosState>) -> Result<(), String> {
    let dir = state.store_dir.lock().unwrap().clone();
    sync::set_token(Some(token));
    sync::clone(&url, &dir).map_err(|e| e.to_string())?;
    Ok(())
}

#[tauri::command]
pub fn init_store(fingerprints: Vec<String>, state: State<IosState>) -> Result<(), String> {
    let dir = state.store_dir.lock().unwrap().clone();
    store::init(&dir, &fingerprints).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn insert_password(path: String, content: String, state: State<IosState>) -> Result<(), String> {
    let dir = state.store_dir.lock().unwrap().clone();
    let cert = key(&state)?;
    store::insert(&dir, &path, content.as_bytes(), &[cert]).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn git_push(state: State<IosState>) -> Result<(), String> {
    let dir = state.store_dir.lock().unwrap().clone();
    let repo = git2::Repository::open(&dir).map_err(|e| e.to_string())?;
    sync::commit_all(&repo, "passero ios edit").map_err(|e| e.to_string())?;
    sync::push(&repo).map_err(|e| e.to_string())
}
```
Add these to the iOS `generate_handler!` list in `lib.rs`.
